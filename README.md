# spotify_clone
# 🎵 Spotify Clone (Web Player UI)

A responsive **Spotify Web Player Clone** built using **HTML, CSS, and Font Awesome**.
This project replicates the basic layout and UI of Spotify, including sidebar navigation, library section, and music player interface.

---

## 🚀 Features

* 🎧 Sidebar with navigation (Home, Search)
* 📚 Library section with icons
* 🎵 Music player UI layout
* 📱 Responsive design (basic)
* 🎨 Clean and modern UI inspired by Spotify

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3 (Flexbox)**
* **Font Awesome Icons**
* **Google Fonts (Montserrat)**

## ⚙️ Installation & Usage

1. Clone the repository:

```bash
git clone https://github.com/your-username/spotify-clone.git
```

2. Open the project folder:

```bash
cd spotify-clone
```

3. Run the project:

* Open `index.html` in your browser
